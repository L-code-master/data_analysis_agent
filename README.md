# 经营诊断 Agent —— 淘宝店铺数据分析

> 上传千牛导出的报表（订单 / 生意参谋 / 账房 / 退款 / 广告 / 采购），
> 自动识别字段、按官方口径算指标、产出**每个数字可溯源**的 HTML 诊断报告；
> 还能**对话提问**：查数类问题走语义层直算（零 AI 成本），
> "为什么"类问题进入 Agent 循环（LLM + 工具，数字全部来自工具返回）。
>
> 告诉卖家：为什么涨、为什么跌 —— 而不是再给一张图表堆砌的报表。

**当前版本 v1.4** · 后端 FastAPI + DuckDB + SQLite · 前端 Vite + React + TS
**验证状态**：19 个测试模块 / 690+ 项断言全绿（含并发互斥、DuckDB 真实执行与全栈冒烟）

---

## 它解决什么问题

中小卖家不缺数据（千牛里全是报表），缺的是**结论**：

| 痛点 | 本项目的做法 |
|---|---|
| 报表看不懂，数字对不上 | **语义层**固化淘宝官方口径（支付转化率、退款按申请日归属…），16 个指标可查可验 |
| 同一个"毛利率"三个数 | 口径显式分离（M13 财务口径 / M14 推广口径），歧义报错而不是猜 |
| 不敢信 AI 编的数 | 指标全部由**确定性 SQL** 计算（不经过 LLM），报告里每个数字可点开溯源 |
| 数据敏感不敢上传 | 租户目录隔离 + 沙箱网络隔离（`SANDBOX_NETWORK_ISOLATED=true`），默认不出网 |
| 想先试试不敢付费 | **下载样例 → 注册送 1 次体验 → 5 分钟看完整报告**，再决定买不买 |

## 核心流程

```
注册(送1次) → 上传千牛导出(一个多表Excel自动拆分) → 字段映射(置信度1.0免确认,
              低置信度人工把关,同结构第二次免确认) → 诊断(SSE实时进度:
              导入STG→ETL→质量门→算指标→出报告) → HTML报告(统计卡片+
              口径对比+趋势图异常标记+异常日定位+商品拆解+周度对比+
              指标表+口径声明+口径版本快照) → 额度用完引导购买
```

- **诊断一次扣 1 次额度，失败自动退还**（不为失败买单）
- 支付当前为**人工核销**（收款码 + 后台确认），支付宝商户号就绪后切 `BILLING_PROVIDER=alipay`
- 定价：体验价 ¥49（每人限 1 次）/ 单次 ¥199 / 5 次包 ¥799

## 六层架构

```
A 前端层   React 9 页面（上传/映射/进度/报告/购买…）
B 接口层   FastAPI REST + SSE，JWT 鉴权，租户绑定
⑥ 交付层   HTML 报告 + 按次计费（额度制）+ 多租户
⑤ 验证层   9 条数据质量门 —— 不过不出报告
④ 记忆层   字段映射确认结果复用（同结构第二次免确认）
③ 上下文层 SQL 渲染器（metric_spec → 按需生成计算 SQL）
② 工具层   淘宝适配器（7 种报表 / 98 字段 / 编码·表头·数值·类型四道处理）
① 约束层   租户目录隔离 + 路径穿越/符号链接防御 + 成本熔断
★ 语义层   DuckDB：16 指标注册表 + 口径规则 + 血缘 + 质量门（横向贯穿）
▣ 存储层   SQLite（元数据/计费，15 表）+ 文件系统（数据/产物/审计）
```

**对话式分析（v1.4）**：查数类问题（"这个月毛利率多少"）走语义层直算，
零 LLM 成本、秒回；"为什么"类问题进入 Agent 循环 —— LLM 编排 5 个确定性
工具（算指标/商品拆解/周对比/异常日/指标目录），**模型只负责组织语言，
数字全部来自工具返回**，并有循环守卫（相同调用第 3 次阻止）与上下文
多级压缩兜底（L1 截断 → L2 分级删除 → L4 超限紧急压缩；L3 LLM 摘要
已实现、待接入引擎，接入前不宣传"四级"）。

## 配置

复制 `.env.template` 为 `.env`，必填项：

| 变量 | 说明 |
|---|---|
| `APP_SECRET_KEY` | JWT 签名密钥，随机 64 字符，**必须修改** |
| `LLM_API_KEY` | OpenAI 兼容端点的 API Key（对话归因功能需要；不填则该功能降级，诊断/查数不受影响） |
| `LLM_BASE_URL` | OpenAI 兼容端点地址 |
| `LLM_MODEL` / `LLM_MODEL_HEAVY` | 主力 / 复杂归因模型名 |

其余（成本熔断、上传限制、JWT 时效、定价、沙箱隔离等）见 `.env.template` 内注释，均有合理默认值。

依赖安装（Python 3.12）：

```powershell
pip install -r requirements.txt
# 前端依赖由 start.ps1 自动安装，也可手动：
cd web && npm install
```

## 隐私与安全设计

- **数据不出网**：沙箱网络隔离默认开启（`SANDBOX_NETWORK_ISOLATED=true`），
  上传文件只进本机租户目录，不发给第三方
- **租户目录隔离**：每个租户独立目录，路径穿越 / 符号链接攻击在文件系统层被拒
- **数据不进大模型**：诊断与查数全部走确定性 SQL；对话归因只把
  schema 与计算结果给模型，原始行数据不进上下文
- **审计留痕**：上传 / 诊断 / 计费 / 对话全链路审计日志，追加写不可改
